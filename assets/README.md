# 固定资产库（给 MiniMax H3 用）

本目录是三部样例剧的 **角色锁脸图 / 场景图 / 道具图**。  
生成每一镜时：**按「上传顺序」原样上传**，提示词里的 `@图片1` `@图片2` 才会对准。

---

## 目录

| 剧 | 路径 |
|----|------|
| 《末班电梯》 | `03_末班电梯/` |
| 《青锋不问名》 | `01_青锋不问名/` |
| 《修图师》 | `02_修图师/` |

每部剧内：

```
角色/   ← 正脸（主锁脸）+ 全身（锁服装）
场景/   ← 主场景静帧
道具/   ← 关键道具
音色/   ← 放置 2–8 秒人声参考 wav/mp3（见各剧音色卡）
00_上传顺序与音色卡.md
```

---

## H3 使用铁律

1. **正脸图整剧不要换底图**（最多换更清晰的裁切版）  
2. 上传顺序必须与该集 `上传清单` / 提示词顶部一致  
3. 每个文件都要在提示词写用途：`人物参考（锁脸）` / `场景参考` / `音色参考`  
4. 台词必须原文；声音用 `@音频X 是音色参考（锁定XX的声线）`  
5. 若暂时没有音色文件：先按音色卡文字描述声线，后续补录音后立刻改用 `@音频`

---

## 音色文件怎么准备（推荐）

用同一人/同一TTS角色，录或导出 **3–6 秒** 中性口播，例如：

> 「一二三四五，今天天气不错。」

保存为：

- `音色/音色_陈岚.wav`
- `音色/音色_许舟.wav`

上传时标：`@音频1 是音色参考（锁定陈岚的声线与语速）`
