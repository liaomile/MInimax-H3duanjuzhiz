# 《末班电梯》整剧大纲 · V3内容改版

| 字段 | 内容 |
|------|------|
| 赛道 | 都市密闭悬疑 · 职场共鸣 |
| 观众承诺 | **你敢不敢用一句真话，换一条命和一份体面？** |
| 卖点画面 | 末班电梯只停奇数层；想出去，先说真话 |
| 落点内涵 | 谎言是连锁的；承担责任比「逃出去」更难，也更值得 |
| 主投平台 | 抖音 / 红果（悬疑+职场）；TikTok 切片导流 |
| 不主投 | ReelShort 恋爱付费墙 |

## 生产规格

16 集 × 5 镜 × 8 秒 → 剪辑约 60–80 秒/集。出片以 `V2_导演精改版` 为准。

> 剧本层：先读 `12_导演诊断书`、`14_全集改法表`。本剧 V4 试点：第01 / 09 / 11 / 15 集（各含 `单集剧本_V4.md` 与 `V3_导演稿提示词/`）。

## 情绪总弧

| 阶段 | 集 | 观众该感到 |
|------|----|-------------|
| 建置 | 01–03 | 怕、好奇、不信任 |
| 撕裂 | 04–08 | 心疼、愤怒、想对质 |
| 崩盘 | 09–12 | 窒息、互相指责、求生 |
| 选择 | 13–16 | 愧疚后的释然（正向，不狗血虐到底） |

**高潮点（必须硬）**

- 第 **03** 集：急坠 = 有人说谎的肉感惩罚（小爆）  
- 第 **07** 集：层数只剩三层 + 失踪者名字第一次被念出（中爆）  
- 第 **11** 集：小满承认自己是「盯梢」→ 四人信任碎裂（大爆）  
- 第 **15** 集：谁先签名 = 尊严对决（情感高潮）  

## 人物代价（改版核心）

| 角色 | 秘密 | 说出来的代价 |
|------|------|----------------|
| 许舟 | 线上事故推给实习生 | 可能被公司追责、陈岚鄙视 |
| 老周 | 关过故障上报 | 饭碗与良心对撞 |
| 陈岚 | 删过客户差评/反馈 | 专业名誉裂开 |
| 小满 | 被要求监视失踪同事 | 被当成内鬼，差点被赶出轿厢 |

**失踪同事**不再是背景板：他曾被困同款电梯、报修被压下，如今生死未明——真话关乎一条命。

## 单集万能结构（剪辑时自检）

1. 0–3s：异常/冲突已发生  
2. 本集必须有一次「压→松」或「松→压」  
3. 集尾钩子强过本集任何一句解释  
4. 禁止纯讲解规则超过 8 秒
