# 第15集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 本集是"归还与致敬"：场景从修复室转博物馆，全剧最温暖的一集；基调克制、不煽情、不做仪式性大哭。全集无配乐。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 工作人员协助入柜、三人跟在侧，人员身份不清；无开场关键物节奏 | 装柜只拍白手套的手与小臂（不引入无资产的正脸角色）；开场0–2秒画直接入柜；三人并排站位与轴线写死（林左周右顾中） |
| 镜02 | 要求模型在铭牌上呈现「江行图 · 并记救人者」可读文字；台词另一句 | 牌面在模型画面里保持空白反光，铭文字全部后期（全剧最重要文字落点，零错别字）；林夏只说4字「该写上了。」 |
| 镜03 | 台词「谢谢你等我们。」7字+鞠躬，情绪说明偏直白 | 保留鞠躬、台词微调7字「谢谢你，等我们。」；30度鞠躬停一拍、有湿意不落泪；明确禁花字、禁泪痕特效 |
| 镜04 | 顾老「晚了……但还不晚。」7字+拭泪，容易演成哭戏 | 改为6字「不晚，就不晚。」；拭泪动作限定为"手背很快按一下眼角"；顾老拍林夏手背的回应动作替代煽情 |
| 镜05 | 周渡长句「存档。以后谁改铭牌，有底。」11字解释 | 压到6字「存档，留个底。」；存档照片如需入镜，后期用干净展柜静帧替代手机屏；集尾保持余韵不抛悬念 |
| 镜06（新增补镜） | 无 | 4秒 Turbo 展柜空镜：玻璃上一道虚焦人影反光缓缓冲过再消失（温暖版"画中人"回收，无五官无冷色），插在镜03→镜04之间；无对白、无正脸、无可读字；有鬼影观感即弃用 |
| 全片 | 博物馆易被模型做成冷白美术馆光 | 逐镜锁定暖柔射灯+木质墙面+暗部柔和；展厅底噪替代音乐；服装/发型与修复室段连续 |

## 三、后期文字清单（模型不渲染）

1. **铭牌（最重要）**：「江行图 · 并记救人者」（最终定名与全剧字幕组核对），后期金属牌贴字质感，零错别字。
2. 镜05如展示周渡拍的存档照：用后期干净展柜静帧，不用模型屏摄。
3. 全片不出现任何其他可读标签、导览文字、其他展品铭牌（背景铭牌一律虚掉或避开）。

## 四、跨集衔接锚点

- **承上（第14集→第15集）**：用"同一幅江行图"匹配剪接——第14集镜05案上平静江面 → 本集镜01展柜中同位置江面；光线从窗光/台灯过渡到暖柔射灯，色温保持暖黄统一。
- **启下（第15集→第16集）**：本集三人并立展柜的安静定格 → 第16集镜01回到修复室空镜（空画案、洁净台面、笔匣收起），以"物归其位"开场；周渡的"存档"手机在第16集不再出现（工作结束）。
- **情绪承接**：镜06人影反光是"画中人"最后一次出现；第14集墨色散回江天、第15集只剩玻璃上一道像观众自己的影子——两次回收完成后，第16集新画裂纹才是新故事而非旧规则延续。
- **服装道具**：林夏从围裙换成简洁便装但发型不变；顾老始终深色中式外套；展柜、铭牌条、木框为博物馆段独有道具。

## 五、缺失/风险资产

1. **三个音色文件仍缺**；本集三人均有台词，文字卡已锁（林夏轻、顾老沉、周渡淡）。
2. **博物馆铭牌成品道具缺失**：模型画面用空白牌+后期贴字方案，需要美术提供铭牌文字排版（含字体、字号与做旧程度）。
3. **博物馆工作人员**无角色资产：已规避为"只拍白手套的手"；如必须露人，需补群演角色卡。
4. 风险点：玻璃反光容易生成出清晰鬼脸/陌生正脸——镜06与镜01/03玻璃面出片逐一检查，清晰人脸一律弃用。
5. 场景图 `场景_博物馆走廊.jpg` 需确认含可用的展柜角度；若展柜与走廊不在同一画面，本集以展柜近景为主、走廊纵深只做虚化背景。

## 六、A/B 执行建议
