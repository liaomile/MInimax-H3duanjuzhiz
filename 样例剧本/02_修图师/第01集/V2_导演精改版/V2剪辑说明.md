# 第01集 V2 剪辑与 AB 对比说明（修图师）

- 版本：V2 导演精改版（覆盖旧版 V2 模板稿；V1 原件保留在本集根目录，未改动）
- 依据：`11_导演V2规范_本地H3成片提示词升级.md` + 末班电梯 V2 标杆格式
- 生成轨道：镜01–05 成片轨 8s/0.65MP/关 Turbo/对白18步、无对白15–16步；镜06 补镜 4s/0.45MP/Turbo 6–8步

## 一、每镜 V1 → V2 差异表

| 镜 | V1 原要点 | V2 关键改动 |
|---|---|---|
| 镜01 | 中景开场+口述旁白式说明，无运镜规定 | 改纯无对白建立镜（16步）；写死轴线（林夏左1/3面朝右、门在右）、唯一≤8%缓推、安全区、首尾帧；风格锁逐字 |
| 镜02 | 原 V1 为「林夏发现异常+长台词」混合镜 | 拆为手部特写（本剧强项）：镊子压纸纤维一个动作，15步，固定俯拍，无正脸无文字 |
| 镜03 | 与镜02合在同一镜，台词两句 | 独立反应+台词镜，只保留林夏一句「桥墩下面……多了一块。」（10字），18步，口型对齐 |
| 镜04 | 原 V1 直接「她说出画中有人」 | 独立无对白异常镜：桥底伞影墨色渐变显形，明确「不跳吓、无清晰人脸字痕」，尾帧供后期圈示 |
| 镜05 | V1/旧V2 有两句台词（含伞样式长句） | 只留气声一句「画里……有人。」（5字）；伞样式长句移下集钩子字幕；集尾单镜定格 |
| 镜06补镜 | V1 无 | 新增4秒 Turbo 空镜：台灯下修复工具静照，插在镜01→镜02之间 |

AB 对比重点：V1 是「一镜塞多事件+多句台词」；V2 拆成 建立/手部/反应/异常/钩子 五个单义镜头，异常靠墨色渐变而非惊响，钩子只留一句气声。

## 二、剪辑顺序与时长账

| 顺序 | 素材 | 时长 |
|---|---|---|
| 1 | 片头（剧名/集数卡，统一模板） | 3s |
| 2 | 镜01 白天修复室建立（缓推） | 8s |
| 3 | **镜06补镜** 工具静照（Turbo空镜） | 4s |
| 4 | 镜02 镊子压纸纤维特写 | 8s |
| 5 | 镜03 林夏发现「多了一块」 | 8s |
| 6 | 镜04 桥底伞影显形 | 8s |
| 7 | 镜05 林夏「画里……有人。」定格 | 8s |
| 8 | 片尾（关注引导+下集钩子字幕） | 5s |

- 核心时长：5×8s + 补镜4s = 44s；加片头3s、片尾5s = **52s**。
- 成片落在 56–60s 目标区间的做法：集尾定格评论提问卡约2s + 硬切间微停顿预留2–4s ≈ **56–58s**；若平台要满60s，片尾延至7s。不额外加镜头。

## 三、后期文字 / 老照片内容清单（模型不渲染清晰文字）

## 六、执行难点

1. 镜04「墨色渐变显伞影」尺度：要可辨但不恐怖，建议同种子出2–3版，选「像旧画原有墨痕」的一版。
2. 镜02 手部稳定度：0.45–0.65MP 下镊子尖易抖，靠 Turbo 补镜先垫氛围，成片镜步数保持15–16，必要时同种子重抽。
3. 镜05 气声短台词口型：5字句留白多，配音与口型都要轻，避免拍成惊恐。
