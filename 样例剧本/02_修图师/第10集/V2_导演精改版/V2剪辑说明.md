# 第10集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 本集主场景：白天档案室（高窗暖黄侧光）；全集无配乐。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 开镜先拍柜门与尘絮，关键物（信）出现晚；风格锁沿用修复室台灯描述 | 开场0–2秒柜门直接拉开、2–5秒信笺到手（2秒内出关键物）；改为档案室高窗光；补镜钥匙仍挂锁孔承接第09集 |
| 镜02 | 台词「……完整的。没有被撕。」8字带省略号停顿，信息靠台词 | 压到5字「没有被撕。」；改为捻折口、查四边的手部近景；周渡只用悬空两指提示"慢"，不说话 |
| 镜03 | 要求"竖行墨迹清晰可读"，等于逼模型渲染书法文字 | 纸面只有模糊竖行墨痕、不成字；念白压到8字「我救人，被写成逃。」；信件全文改后期静帧贴图+下三分之一字幕 |
| 镜04 | 台词「我抄进云盘。纸本别离手。」10字且含操作解释；屏幕界面交给模型 | 台词6字「纸本，别离手。」；手机屏只有取景框亮屏、无文字；云盘界面全部后期UI贴图 |
| 镜05 | 台词「有人。」之外依赖灯晃与脚步，尾帧"门把手微动"较含糊 | 保留2字台词；写死门把手往下动半分停住、门外人影只以门缝光被遮呈现，门外人绝不露形（身份留第11集监控） |
| 镜06（新增补镜） | 无 | 4秒 Turbo/6–8步：高窗光柱+展平信纸+尘粒上浮的静物空镜，插在镜03→镜04之间做真相静默拍；无对白、无正脸、无可读字 |
| 全片 | 风格锁与修图师规范不符 | 逐字统一导演风格锁；林左周右轴线全集写死；首尾帧逐镜交接（柜线、信位、封口、门把） |

## 三、后期文字清单（模型不渲染）

1. 镜03信件关键句字幕：「我救人，被写成逃。」（下三分之一居中，跟念白）；如要展示"信件全文"，美术另出做旧信笺静帧，后期 Ken Burns。
2. 镜04云端备份界面（相册/云盘上传成功）一律后期 UI 贴图，手机屏素材里不出现可读界面。
3. 镜05集尾提问卡：建议「门外，是谁？」。
4. 信笺、柜门、档案室任何标签编号均不出现可读文字。

## 四、跨集衔接锚点

- **承上（第09集→第10集）**：柜门从"一线"继续拉开；铜钥匙仍挂锁孔；林夏全程白手套；周渡补光位（画面右）与第09集镜05一致。
- **启下（第10集→第11集）**：本集尾门外脚步+门把手停住不揭晓人；第11集镜01时间跳到"次日修复室"，以电脑显影记录被清空开场，门外对峙由镜02监控回放补叙（深色外套背影、非馆员工牌——工牌信息后期UI呈现）。
- **道具连续性**：旧信笺从取出→展读→入透明保护袋不离手；第11集信仍在林夏手中/保护袋内；透明保护袋为跨集同一道具。
- **光线连续性**：档案室高窗暖黄光与修复室暖黄台灯同色温；手机冷白屏光始终弱于主光。

## 五、缺失/风险资产

1. **音色文件三个全缺**：`assets/02_修图师/音色/` 为空，本集靠文字卡（林夏中柔气声 / 周渡理性略干）。
2. **道具_旧铜钥匙.jpg** 缺：镜01锁孔挂钥匙依赖第09集生成形态，建议两集同批同种子出图。
3. **做旧信笺"全文版"**：现有 `道具_旧信笺.jpg` 用于锁载体；若后期要上"可读全文"，需美术另出一张高分辨率做旧信笺（模型只出模糊墨痕版）。
4. 风险点：模型可能把信纸墨痕生成成可辨认的乱码字——出片检查纸面，乱码明显的批次弃用，靠"俯拍+虚焦+后期贴图"规避。
