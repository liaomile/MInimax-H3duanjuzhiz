# 第14集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 本集进入收束段：总基调**温暖克制、真相正向**；三件事——补完最后一笔、画中人释然散回墨色（规则终止）、林夏头痛消失。全集无配乐。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 无对白补裂纹，但光线无变化设计，与普通修复镜无差别 | 明确收束光线弧：开场台灯为主→窗光渐亮盖过台灯（镜头内平缓渐变）；鸽哨/扫帚等清晨环境声托"天亮了" |
| 镜02 | "撑伞背影侧脸露笑意、墨色散开"——写实脸/鬼影高风险，且无边界约束 | 锁死为水墨笔触：无写实五官、无白眼、无黑雾、无飘移，只是墨色柔和洇进江天；给备选方案（只拍墨散+林夏松眉心，不做笑意） |
| 镜03 | 林夏「……不疼了。」+周渡松气，表演说明简单 | 保留3字台词，动作链写死：习惯性按太阳穴→松开→等疼（没来）→确认；明确不做头痛闪回；周渡松肩、手机已黑屏（直播已关） |
| 镜04 | 周渡「它只是要被看见。」7字，点题句容易被做成金句 | 微调8字「它只是，想被看见。」；双人侧背看画构图，手机倒扣案角；明确不加金句花字动效 |
| 镜05 | 收笔关补光+平静江面定格，但镜尾仍写"悬念定格/下集钩子"套路 | 本集不抛强钩子：笔匣合拢、关补光、退一步让出画案，余韵定格；转场交剪辑用"同一幅画"匹配第15集展柜 |
| 镜06（新增补镜） | 无 | 4秒 Turbo 纯光线空镜：窗光光斑缓移过空画案、尘粒上浮、双暖光相接，插在镜02→镜03之间，用光线写"规则终止"；无对白、无正脸、无可读字 |
| 全片 | 风格/光线与前段悬疑段无区分 | 明确本集起窗光成为主光、台灯退为点缀；暗部依旧柔和；所有超自然音效（风咽/铃/心跳）全部禁止 |

## 三、后期文字清单（模型不渲染）

1. 本集几乎无文字信息：唯一上屏的是镜04点题句的常规台词字幕。
2. 镜05如需片尾引导，用黑底极淡白字，不做花字。
3. 画内无新增题跋、印章文字；任何"修复完成/年代作者"信息如要交代，放到第15集博物馆铭牌统一呈现。

## 四、跨集衔接锚点

- **承上（第13集→第14集）**：时间跳次日；门已关上、画案整洁、信袋收入文件盒；后人离场（不强行拍和解同框）；江行图仍在案，新显影人形在镜02散回墨色。
- **启下（第14集→第15集）**：镜05平静江面定格 → 第15集镜01博物馆走廊，同一幅江行图被移入展柜（匹配剪接：墨色江面→展柜中同位置江面）。
- **道具/状态**：手机直播在本集开始前已结束（屏幕暗），第15集周渡的手机只用于拍照存档；笔匣、补光灯为收束动作道具，无需新增资产。
- **光线弧线（写进镜头）**：镜01台灯主光→镜01尾/镜06窗光满室→镜03–05窗光主、台灯辅，三集（14–16）光线持续偏暖亮，直到第16集结尾回归日常暖光。

## 五、缺失/风险资产

1. **三个音色文件仍缺**；本集只有林夏、周渡各一句，文字卡已锁。
2. 镜02是全剧最容易"翻车成鬼片"的一镜：已给水墨边界与弃用标准；建议多出几个候选，导演组人工挑。
3. 光线渐变依赖生成稳定性：如单镜内渐变不自然，拆成"台灯版/窗光版"两条同机位素材由剪辑叠化。

## 六、A/B 执行建议

- 主对比镜02：有无"侧身笑意"两版——若笑意版有任何恐怖观感，一律用纯墨散版。
- 镜06补镜验证收束节奏：悬疑剧观众对"纯光线空镜"的接受度，用14集完播与15集引流率共同评估。
