# 《修图师》整剧大纲 · V3内容改版

| 字段 | 内容 |
|------|------|
| 赛道 | 非遗悬疑 · 真相伦理 |
| 观众承诺 | **真相会毁一个家族的名声，你还修不修？** |
| 卖点画面 | 每修好一处，画里就多一个人 |
| 落点内涵 | 被涂改的历史也是暴力；匠心是让该被看见的人被看见 |
| 主投平台 | 抖音 / 红果（非遗+悬疑）；文化向切片 |
| 不主投 | 海外霸总恋爱赛道 |

## 生产规格

16 集 × 5 镜 × 8 秒。出片以 `V2_导演精改版` 为准。

> 剧本层：先读 `12_导演诊断书`、`14_全集改法表`。本剧 V4 试点：第01 / 05 / 12 / 15 集（各含 `单集剧本_V4.md` 与 `V3_导演稿提示词/`）。

## 情绪总弧

| 阶段 | 集 | 观众该感到 |
|------|----|-------------|
| 建置 | 01–04 | 好奇、发毛、怀疑师傅 |
| 撕裂 | 05–09 | 心疼师傅、愤怒后人 |
| 开战 | 10–13 | 紧张、爽（直播打脸）、泪 |
| 落点 | 14–16 | 释然、敬意、系列欲 |

**高潮点**

- 第 **03** 集：收件人姓顾（小爆）  
- 第 **05** 集：画中幼年顾老 + 头痛爆裂（中爆）  
- 第 **11–12** 集：证据被删→直播硬刚（大爆连击）  
- 第 **15** 集：铭牌改写（情感落点）  

## 人物代价

| 角色 | 欲望 | 代价 |
|------|------|------|
| 林夏 | 修好画、求真 | 头痛共情；可能毁师傅名声、被告 |
| 周渡 | 证据与正义 | 云端被攻、职业风险 |
| 顾老 | 保恩人后人 | 一生谎言；当众承认覆盖 |
| 后人 | 保家族叙事 | 崩溃后接受「先人是救人者」 |

## 单集自检

- 每集必须让「修 / 不修」的天平晃一下  
- 禁止连续两集纯查档无情绪爆点  
- 直播集（12）台词要短、狠、可切片
