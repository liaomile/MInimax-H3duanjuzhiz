# 第16集《修图师》V2 剪辑说明（导演精改版 · 大结局）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 全剧最后一集：**日常重新开始**。新画普通裂纹、什么都没发生；周渡收起了手机；林夏重新开工。全集无配乐、无彩蛋鬼脸，基调安全、温暖、安定。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 新画裂纹出现但未彻底排除"又有异常"的观感，结尾季有继续埋伏笔惯性 | 明文锁死：自然旧损、无显影、无手指、无墨变；手指悬而不点；明确"不给第17集绑定、不做片尾彩蛋鬼脸"，给观众安全确认 |
| 镜02 | 周渡仍有举手机/开播习惯动作的惯性，"正常活"台词但人物弧光未收 | 周渡全程不拿手机、端两杯热水入场，肩膀放下；7字「这次，正常活儿？」玩笑尾音；林夏只笑不出长台词 |
| 镜03 | 林夏「先看看。」收尾，偏悬念感 | 改为全剧最后一句4字台词「开始修吧。」；重复第01集戴手套摆工具的职业动作但节奏更松；近景推近收尾 |
| 镜04 | 修复蒙太奇与前面集数雷同，未强调"无异常" | 四步动作写清（润纸/挑边/压平/补色），逐拍注明干净无显影、无时间流逝特效；与镜01同机位裂纹形成呼应 |
| 镜05 | 窗台工具收尾意象有，但江行图出现方式不明 | 明确为"博物馆入展照片（明信片大小，可用第15集展柜静帧做衍生）或卷轴二选一"，不编造新道具；构图与第01集窗台镜首尾呼应；"全剧终"字卡走后期 |
| 镜06（新增补镜） | 无 | 4秒 Turbo 房间空镜：窗光满室、台灯只剩柔和轮廓、可有虚焦工作背影；插在镜03→镜04之间，给观众"故事真的结束了"的呼吸；无对白、无正脸、无可读字 |
| 全片 | 收束集易被拍成"新坑预告" | 三令五申：无黑影、无新显影、无心跳/电流/风咽；光线明亮稳定；周渡无手机=人物弧光终点 |

## 三、后期文字清单（模型不渲染）

1. 「全剧终」字卡：黑底白字或叠在镜05画面下部安全区，不遮挡江行图照片；字体建议与第01集标题卡同系列，完成首尾呼应。
2. 镜05江行图入展照片：由第15集展柜静帧裁切印制为明信片质感，画面内的展牌如可读必须与第15集后期铭牌文字一致，否则做虚。
3. 新画无任何题跋、印章、标签可读内容；如评论引导卡需要，放黑场，不压在正片画面上。

## 四、跨集衔接锚点

- **承上（第15集→第16集）**：展柜定格 → 修复室空案 → 新画落案；博物馆暖射灯回到修复室窗光+台灯（暖黄色温连续，不做冷暖跳）。
- **全剧首尾闭环（与第01集的呼应，建议剪辑对照执行）**：
  1. 镜01俯拍裂纹 ↔ 第01集裂纹显影：同机位、同光向，区别只在"裂纹什么都没发生"。
  2. 镜03戴手套摆工具 ↔ 第01集开场职业动作：动作相同，节奏更松。
  3. 镜05窗台工具静帧 ↔ 第01集窗台镜：同位置、更明亮。
  4. 周渡从"举手机开播"到"端热水、手机消失"：人物弧光闭环，不额外交代。
- **情绪线收束顺序**：第13集对峙（最冷）→ 第14集墨散、不疼了（释然）→ 第15集入展、鞠躬（致敬）→ 第16集新画、开工（日常）。光线同步：台灯主光 → 窗光渐亮 → 博物馆暖射灯 → 满室日常窗光。
- **超自然元素总账**：规则终止于第14集镜02；第15集镜06最后一道温柔反光；第16集零超自然（镜06空镜也明确禁止任何异象）。
