# 第13集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 本集是冲突对质集，但情绪总原则：克制、可收尾——对方是被家族叙事困住的人，不是反派符号；真相落点是"和解式正名"。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 后人长句「族谱写的是逃……你们在污先人？」17字，情绪激烈指画 | 压到6字「族谱写的是逃！」；改为"指尖离纸半尺、手悬着发颤"的克制质问；林夏只做扶案、挪笔的护物动作，不回嘴 |
| 镜02 | 周渡长句「证据在画里，也在纸上。族谱可以错，笔墨难欺。」22字超限 | 压到6字「画和信，都在。」；用"手机让画与信袋同框"的动作呈现双证；大道理全部删掉 |
| 镜03 | 林夏「他自己写的——救人，却被写成逃。」13字超限 | 压到7字「他写的：我救人。」；取信、铺平、抬眼的动作链写死；信中长句继续走第10集建立的字幕版式 |
| 镜04 | 顾老「覆盖是我做的。恩人救人，不该再被埋。」17字，配鞠躬+眼眶发红 | 压到5字「是我盖住的。」；只欠身不鞠躬不下跪不哭；补镜06（按门把决定）承担情绪铺垫，真相不重复解释（第09集已交代动机） |

| 镜06（新增补镜） | 无 | 4秒 Turbo：顾老的手按门把停一拍再松开的特写（无正脸），插在镜03→镜04之间，把"出面作证"做成决定动作；无对白、无可读字 |

## 三、后期文字清单（模型不渲染）

1. 镜03信件关键句字幕：「我救人，被写成逃。」沿第10集字体版式（本集台词只说前半句，字幕可只上"我救人。"避免重复，由剪辑定）。
2. 直播UI：红点、在线人数保持、弹幕做"愣住—理解—声援"的三波节奏，禁止嘲讽网暴类弹幕（本剧基调正向）。
3. 集尾提问卡：建议「真相被看见之后呢？」。
4. 族谱只存在于台词，不生成族谱道具与文字。

## 四、跨集衔接锚点

- **承上（第12集→第13集）**：门仍开着、后人站位在画面右、林夏虚护手势、周渡手机高度全部承接第12集镜05定格；江行图新显影人形是本集核心物证。
- **启下（第13集→第14集）**：冲突以"后人垂手低头"收束；第14集镜01时间跳到次日，林夏补最后一处裂纹，后人离场不在画面里（和解不强行同框，留白）。顾老仍在修复室。
- **道具**：透明信袋、江行图、直播手机三件物证在同一张画案上；补镜镜06的门把与门位和第12集闯入的门一致。
- **光线**：门开带入的暖白日光与台灯暖黄光统一；本集结束时门可留一条缝，为第14集的安静日光做铺垫。

## 五、缺失/风险资产

1. **后人角色卡缺失**（重点）：本集后人有半身与三分侧脸，跨镜换脸风险高；建议本集生成前补拍/补绘一张 `角色_后人_正脸.jpg`，否则所有后人镜头必须同批次同种子出。
2. **后人音色缺失**：已给文字卡（中年男声、发紧不嘶吼）。
3. **三个主角音色文件仍缺**。
4. 风险点：顾老"欠身"幅度别被模型做成下跪/痛哭——提示词已限定，出片检查。

- 镜06补镜为可选情绪节拍：去掉后节奏更硬，留下后顾老作证更有重量，按完播决定。
