# 第09集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜（均在本目录）。本文件只指导剪辑与后期，模型提示词里不写剪辑指令。
> 原始 V1 五镜提示词保留在上级目录未改动；本版为同素材同种子 A/B 对比的 V2 版。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 顾老开场即长句坦白（约20字），三人同框信息平铺；无冷开场钩子 | 唯一台词压到5字「我盖过一处。」；0–2秒台灯灯丝极轻嗡闪作2秒异常；林夏、周渡只用"镊子悬空、握手机的手停住"反应 |
| 镜02 | 顾老长台词（20字+），镜头带脸中景，情绪靠台词解释 | 台词压到8字「为了保他的后人。」；改为手部近景，指腹停在覆盖处不涂抹；林夏镊子轻颤作反应；不要求模型渲染任何题跋/印记 |
| 镜03 | 林夏长句追问（约18字），过肩镜带明显推近+情绪词 | 台词8字「救人的，该被看见。」；顾老以闭眼+一下点头作答；结尾"手停内袋口"给镜04埋动作 |
| 镜04 | 钥匙交付与长解释同镜，道具来源不明 | 台词11字「旧柜里，有他没寄的信。」；钥匙（缺失资产）给出生成描述与"后期静帧贴图"备选；手在掌心停半秒替代情绪形容词 |
| 镜05 | 原场景仍在修复室、用台词收束集尾 | 跨场景硬切白天档案室，钥匙动作接力（手里→锁孔）；全镜无对白；柜门只开一线定格，暗部柔和无白雾无鬼脸 |
| 镜06（新增补镜） | 无 | 4秒 Turbo 补镜、6–8步、0.45MP：修复室空画案，窗风掀动画角一次；插在镜02→镜03之间作情绪呼吸口；无对白、无正脸、无可读文字 |
| 全片 | 风格锁为旧版"轻悬疑/琥珀褐/低饱和"，与导演规范不一致 | 逐字统一风格锁：写实都市电影感；老城区日光偏暖黄、室内工作台台灯集中光，暗部柔和；文物与纸面质感细腻；解谜不恐怖，无鬼片跳吓 |
| 全片 | 镜间衔接靠"保持连续"一句话 | 每镜写死首帧/尾帧（手的位置、钥匙、门线、光位），镜04→镜05用同一把钥匙跨场景硬切接力 |
| 全片 | 声音设计笼统 | 每镜写实环境声与动作声（锁舌"嗒"、钥匙落掌、纸绢翻动、远处鸽哨）；全集无配乐 |

## 三、后期文字清单（一律后期呈现，模型不渲染）

1. 镜05集尾提问卡（黑底白字）：建议「旧柜里，藏着什么？」（1.2s，不进提示词）。
2. 镜02若需向观众解释"被盖住的一笔"：后期插入江行图静帧（Ken Burns 缓推）+一行小字，不生成新视频。
3. 全集无信件、铭牌、屏幕文字需要上屏（信在第10集才展开）。

## 四、跨集衔接锚点

- **承上（第08集→第09集）**：第08集尾顾老「这幅画有问题……一半，是我」。第09集镜01首帧即同台灯、同站位，顾老接「我盖过一处。」，硬切不回闪。
- **启下（第09集→第10集）**：第09集尾柜门只开一线、钥匙挂锁孔；第10集镜01首帧柜门继续拉开、林夏戴手套从同一格柜取出信笺，周渡手机补光位置不变（他永远画面右）。
- **道具连续性**：旧铜钥匙（镜04出现→镜05入锁）在第10集开镜仍挂锁孔；江行图全集留在修复室画案，本集不出修复室。
- **光的连续性**：修复室暖黄台灯光全集不变；档案室为白天高窗暖黄侧光，与修复室同源色温，避免跨场景跳色。
