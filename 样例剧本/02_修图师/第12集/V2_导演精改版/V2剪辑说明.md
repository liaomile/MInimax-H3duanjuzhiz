# 第12集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 本集是全剧第一个大爆点（公开直播修复→救人墨色显影→后人闯入），但仍按"解谜不恐怖、克制不狗血"执行。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 台词「公开修。边修边录，谁也删不干净。」14字超限，直播红点即出现交给模型 | 台词7字「公开修，全程录。」；手机背面朝镜头、界面零渲染，红点/推流全部后期UI；顾老在场点头（补第三人轴线） |
| 镜02 | 台词「三万了……别抖。」把人数交给表演与台词 | 周渡只剩2字「别抖。」；第一笔全过程给手部；人数/弹幕后期UI；新增推近≤8% |
| 镜03 | 要求"画中浮现撑伞者拉住落水人"，容易被模型做成写实鬼影 | 显影明确为水墨笔触形态显影（伞弧→伸出的手臂→"拉住"定格），无写实人脸、无发光描边、无"叮"音效；林夏只说3字「看见了……」 |
| 镜04 | 评论内容「这是救人」「族谱撒谎了吗」两条+周渡「他们看到了。」挤一镜 | 一镜一说话人：周渡5字「他们看到了。」；两条弹幕后期UI滚动；林夏不抬眼、继续下一笔 |
| 镜05 | 闯入者怒喝「停——不许再修！」7字带破折号喊，正脸有露脸风险 | 压到5字「不许再修！」，压怒不破音；闯入者全程侧脸/半侧身（无角色资产、禁覆盖主角锁脸）；护画动作"虚护不按纸"；门光暖调不泛白 |
| 镜06（新增补镜） | 无 | 4秒 Turbo：笔锋抬起、一滴墨悬而不落、虚焦人形在后的极近特写，插在镜03→镜04之间，给大爆点半秒静默；无对白、无正脸、无可读字 |
| 全片 | 直播UI、弹幕、人数大量需模型生成 | 手机屏在模型画面里只亮屏无字；所有直播UI/弹幕/音效后期统一制作 |

## 二、时长账（成片 ≈56–60 秒）

| 段落 | 内容 | 时长 |
|---|---|---|
| 镜01 | 架手机、「公开修，全程录。」 | 8s+2s | 10s |
| 镜02 | 第一笔、「别抖。」 | 8s+2s | 10s |
| 镜03 | 水墨显影"拉住"、「看见了……」 | 8s+2s | 10s |
| 镜06补镜 | 悬墨特写（静默拍） | 4s | 4s |
| 镜04 | 「他们看到了。」弹幕反应 | 8s+2s | 10s |
| 镜05 | 门被推开、后人闯入、对峙定格 | 8s+2s | 10s |
| 集尾提问卡 | 黑底白字 | 1.2s |
| 下集钩前摇 | 对峙定格+评论引导 | 1.0s |
| **合计** | | **≈56.2s** |

大爆点集如需更快节奏，可把镜01/镜04静帧延展各减1s（总54s），或把省下的时长加到镜03显影（建议显影镜不少于10s）。

## 三、后期文字清单（模型不渲染）

1. 直播UI全套：开播红点、在线人数（镜02给到"3万+"的变化）、进场提示、推流标识。
2. 镜04弹幕（美术统一字体、做滚动）：至少两条「这是救人」「族谱撒谎了吗」，其余做模糊条。
3. 镜05集尾提问卡：建议「他为什么怕这幅画被修好？」。
4. 画内无题跋无印章文字；如后续需要"族谱"对照，另立静帧道具，不在本集模型画面出现。

## 四、跨集衔接锚点

- **承上（第11集→第12集）**：离线硬盘保住数据后的反击落地——架手机即开播；周渡机位旁可瞥见黑色移动硬盘（与第11集同一道具）。
- **启下（第12集→第13集）**：护画—夺画对峙定格直接进入第13集镜01，后人站位（画案前、画面右）、林夏虚护的手势、周渡举手机的高度三镜保持完全一致；手机直播红点在第13集仍然亮着（对质全程被直播）。
- **道具连续性**：江行图位置从画案中央不移位；新显影的"拉住"人形在第13集全程可见，是对质的物证。
- **光线**：门开带入的光保持暖白日间光，与台灯暖黄光同调，禁止冷白强光制造惊悚。

## 五、缺失/风险资产

1. **三个音色文件全缺**；闯入者（后人）同样无音色，本集给了文字卡（中年男声、压怒不破音），建议第13集登场前补录。
2. **后人角色卡缺失**：`角色/` 下只有林夏、周渡、顾老。本集与第13集均有该角色，按文字生成（中年、普通深色夹克），侧脸为主；如需正脸（第13集鞠躬段），强烈建议补一张角色卡，避免跨镜换脸。
3. 风险点：显影人形被模型做成写实鬼影/恐怖脸——已在提示词锁"水墨笔触、无写实人脸、不睁眼"，出片不合格批次直接弃用，可用后期静帧江行图替代运动显影。
4. 直播 UI 与实拍屏幕的透视跟踪在后期完成，模型屏幕统一留灰亮底便于跟踪。

## 六、A/B 执行建议

- 主对比镜03（写实鬼影风险 vs 水墨显影）与镜05（闯入强度：V1喊句 vs V2压怒5字）。
- 镜06补镜验证假设：大爆点前半秒静默提升完播与复看，而非拖节奏。
