# 第11集《修图师》V2 剪辑说明（导演精改版）

> 对应提示词：镜01–05 + 镜06补镜。V1 原五镜保留在上级目录未动。
> 主场景：次日白天修复室；节奏从"被删除的挫败"转向"更稳地反击"，全集无配乐。

## 一、V1 → V2 主要差异表

| 镜号 | V1 做法（问题） | V2 改法 |
|---|---|---|
| 镜01 | 台词「昨晚还在……全没了。」9字，先拍人物反应再给屏幕 | 开场0–2秒直接给空白文件夹异常；台词6字「记录，全没了。」；周渡查线、林夏放下鼠标都用动作交代 |
| 镜02 | 监控背影+台词「不是馆员工牌。」，工牌信息要画面承担 | 台词6字「不是馆里的人。」；监控只给深色外套背影（无正脸、无可读卡证）；"无门禁记录"等改后期UI/字幕 |
| 镜03 | 台词「他们怕这画被修好。」8字、配"压怒"情绪说明 | 台词7字「他们怕画被修好。」；删掉一切情绪形容词，改为深吸气、擦围裙、一根根戴手套的微动作 |
| 镜04 | 台词「本地清了，云端我有备份。」10字解释技术 | 台词7字「云端，还有备份。」；缩略图加载给光感不给字；尾帧埋"第一个缩略图变灰"接镜05 |

| 镜06（新增补镜） | 无 | 4秒 Turbo：江行图静躺保护垫、灯芯一次极轻呼吸的静物空镜，插在镜02→镜03之间（危机中的静物，解谜节点：危险已进门、要修的东西还在）；无对白、无正脸、无可读字 |
| 全片 | 屏幕界面大量交给模型（文件夹/云盘/监控时间码） | 所有屏幕文字、数字、UI一律后期贴图；模型屏幕保持不可读 |

## 三、后期文字清单（模型不渲染）

## 四、跨集衔接锚点

- **承上（第10集→第11集）**：第10集尾档案室门外脚步不揭晓；本集以"次日修复室"开场，用监控回放（镜02）补叙昨夜有人入室，时间跳过对峙——透明保护袋里的旧信笺可在画案一角入画半秒，保持物证连续。
- **启下（第11集→第12集）**：离线硬盘到手、资料随时可能再被远程抹掉 → 第12集镜01三人决定"公开直播修复"，手机支架与红点开场出现；江行图从保护垫移到画案中央。
- **道具/光线**：移动硬盘为新引入道具（无独立资产，文字生成黑色小方块+数据线），第12集周渡机位旁仍可见；台灯光全集暖黄稳定，屏幕冷光始终次一级。

## 五、缺失/风险资产

1. **三个音色文件全缺**（音色目录为空），本集林夏/周渡均靠文字卡。
2. **道具_移动硬盘** 无独立参考，按文字生成，出片后与第12集镜头比对外观一致性。
3. 监控画面是"戏中屏"：需要后期统一做监控 LUT（低照度、轻微噪点）与播放/暂停 UI；模型直出的监控 UI 若出现乱码文字，后期用遮幅盖掉。
4. 旧信笺在本集只作画案一角的连续性道具，不需要展开（避免再次触发纸面乱码）。
