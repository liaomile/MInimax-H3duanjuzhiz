# 平台爆款对标分析（诚实版）

> 结论先说：**不能确定「一定爆」**。爆款是题材×节奏×情绪×算法×投放的共振。  
> 能做的是：按红果 / 抖音 / 海外竖屏短剧的**已验证结构**改剧本，把「能留人、能追更、有内涵」的概率做上去。

调研依据（2025–2026 公开行业复盘，非内部后台）：

- 红果：免费短剧钩子矩阵、完播逻辑；2025 爆款从「纯霸总」转向「真实情感 + 完整逻辑 + 系列 IP」
- 抖音：前 3 秒生死线；悬疑/脑洞/高概念标题友好；复合题材容错更高
- 海外 ReelShort / DramaBox：1 分钟级竖剧；每 10–15 秒加码；5–10 集付费墙前必须极强留存；题材偏 Romance / Revenge / Power-flip

---

## 1. 各平台真正吃什么

| 平台 | 用户要什么 | 结构铁律 | 我们三部的匹配 |
|------|------------|----------|----------------|
| **红果** | 情绪共鸣 + 逆袭/成长 + 逻辑自洽；纯狗血在衰退 | 3 秒冲突；每集新冲突+旧伏笔+情绪爆点；3 集小目标、5 集大高潮 | 中：有主题，缺「痛感—释放」循环 |
| **抖音** | 新奇设定、悬念标题、前 3 秒停滑 | 冲突/悬念/反差/共鸣四选一开场；每 15–30 秒一节点 | 中高：设定够奇，开场与中段仍偏「解谜说明书」 |
| **ReelShort 等海外** | 强情绪、恋爱/复仇、微崖钩连环 | 开场即冲突；结束在未解决；付费墙前高潮密 | **偏低**：三部都不是恋爱复仇主轴 |

### 现在最大的三个问题（必须改）

1. **爽点密度不够**  
   很多集是「查证一步」，缺「压一下—爆一下」。红果/抖音都要求约每 20–30 秒一个情绪节点。

2. **代价不够肉痛**  
   秘密揭开后，人物关系几乎不碎裂。观众要看到：说真话会失去什么，救人才会疼。

3. **平台错配风险**  
   - 硬塞 ReelShort 恋爱模板会毁掉现有内涵。  
   - 正确打法：**抖音 + 红果悬疑/正能量垂类**；海外走 TikTok 切片好奇，而不是 DramaBox 霸总赛道。

## 3. 改版总原则（本轮执行）

| 原则 | 做法 |
|------|------|
| 情绪承诺写死 | 每部只打一句「观众留下来的理由」 |
| 钩子矩阵 | 开场钩 / 中段钩 / 集尾钩，三类轮换 |
| 代价可视化 | 每揭一层秘密，关系或身体付代价 |
| 3/5/10 高潮点 | 第 3 集小爆、第 5/10 集大爆、终局情感落点 |
| 内涵不说教 | 主题用选择场面承载，不靠旁白讲道理 |
| 合规保留 | 不鬼神恐吓、不血腥、不低俗（见合规清单） |

### 三部升级后的「观众承诺」

| 剧 | 旧卖点 | 升级后承诺（情绪+内涵） |
|----|--------|--------------------------|
| 末班电梯 | 奇数层/说真话 | **你敢不敢用一句真话，换一条命和一份体面？**（职场谎言链→集体责任） |
| 修图师 | 修好多一个人 | **真相会毁一个家族的名声，你还修不修？**（被涂改的历史 vs 匠心） |
| 青锋不问名 | 只救人不伤人 | **救一个人，会不会害死更多人？**（侠义不是名，是忍住杀心） |

## 4. 投放建议（别全平台乱投）

1. **主投**：抖音 / 红果 — 悬疑脑洞 + 正向落点  
2. **切片**：TikTok — 高概念 15–30 秒（电梯灭层、空白脸、铭文）导流  
3. **不主投**：ReelShort 付费恋爱墙 — 除非另开「情感线加强版」海外改编
