# 爆款导演法 · 平台铁律版

先读 `平台爆款对标分析_诚实版.md`。不能保证爆，但按铁律剪，留存概率更高。

## 平台铁律（对标红果 / 抖音 / 海外竖剧）

| 秒数 | 必须发生 |
|------|----------|
| 0–3s | 冲突 / 悬念 / 反差 / 共鸣 四选一。禁止寒暄、理书、安静干活 |
| 每 20–30s | 至少一处情绪节点（压或爆） |
| 集尾 5–8s | 钩子强过本集任何解释；停在未完成选择 |
| 全剧 | 第 3 集小爆；约第 5/10/11 集大爆；终局给情感落点 |

剪辑：第 0 秒可闪本集镜 05 最强画面 0.8 秒 + 封面句，再硬切镜 01。

## 三部观众承诺（V3）

| 剧 | 留下来的理由 |
|----|----------------|
| 末班电梯 | 你敢不敢用一句真话，换一条命和一份体面？ |
| 修图师 | 真相会毁一个家族的名声，你还修不修？ |
| 青锋不问名 | 救一个人，会不会害死更多人？你还敢不敢拔剑？ |

## 单集五镜节奏（60–80 秒成片）

| 镜 | 任务 |
|----|------|
| 01 | 第 1 秒异常已发生；一句短台词或无对白纯异常 |
| 02 | 加码或代价显现 |
| 03 | 小反转或对峙 |
| 04 | 身体反应 / 揭示（常无对白） |
| 05 | 集尾钩；人物停在选择上；评论提问后期加 |

## 禁止

- 连续两集纯查证、无情绪爆点  
- 结尾把答案说完  
- 为海外霸总模板毁掉现有内涵  
- 鬼神跳吓、血腥、低俗（见合规清单）

封面句与评论提问见各集 `单集剧本.md`「爆款剪辑」。生成以 `V2_导演精改版` 为准。
