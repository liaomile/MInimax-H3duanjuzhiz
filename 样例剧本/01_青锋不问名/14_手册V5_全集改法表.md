## 手册死线（写进每一集）

| 条 | 落地 |
|----|------|
| 短剧卖下一集 | 每集必须独立结算一次情绪（爽/虐/钩），同时留下未完成 |
| 90 秒节拍 | 0–15 钩子爆炸 → 16–45 反派加压 → 46–75 反转伏笔 → 76–尾 悬念核爆戛止 |
| 黄金前 3 集 | 01 视觉+情感+身份三选三；02 关系复杂化；03 小高潮+更大悬念 |
| 卡点公式 | 高潮 + 悬念 + 情绪 + 未完成，四项缺一不可 |
| 免费区 | 01 落冲突；02–04 小胜利但情绪未解决；**05 = 最后一集免费 = 全季第一次大揭秘** |
| 台词五纪律 | 一句一意；口语；能拍的不说；不说满；动作替台词 |
| 量产 | 一集 ≤2 地点、≤4 常驻角色；第 1 集不许空镜开场 |
| AI 专属 | 定妆锁脸；画面零可读字；一场对话不混模型 |
| 合规 4.10 | 不写速成神功、不写剑飞自行格挡过程；只给结果；不见血 |

## 台词纪律（替换时）

- 每镜最多 **一句、一人、≤8 字**（V2 已守，V5 不放宽）
- 禁止解释已知信息（不要「我是学徒所以不会武」叠两句）
- 集尾提问卡只后期，不进模型
- 铭文「救，或不配持」只后期贴，模型画面零字
