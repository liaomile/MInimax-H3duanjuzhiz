# MiniMax H3 短视频 / 短剧创作模板库

面向 **抖音 + 红果短剧** 可过审发布的 AI 竖屏短剧生产流程。  
按 MiniMax H3 官方提示词公式编写，可直接复制到海螺 / MiniMax Design / 开放平台使用。

> **开源范围**：本仓库发布「选题 → 大纲 → 分集 → H3 提示词 → 合规自查」工作流模板、样例剧本与对白转码工具。  
> **不会上传**：API/SSH 密钥、云端产线脚本、生产主机与链接、未公开改编项目、成片媒体与大模型权重。

## 你怎么用这套模板

```
1. 选题   → 打开「00_赛道选题指南.md」选赛道与钩子
2. 大纲   → 复制「01_整剧大纲模板.md」填 20–40 集骨架
3. 分集   → 复制「02_单集剧本模板.md」写每集 4–8 个 H3 镜头
4. 出片   → 每个镜头填「03_H3提示词模板.md」，上传角色/场景参考图
5. 过审前 → 用「04_抖音红果合规自查清单.md」过一遍
```

推荐起步规格（最稳）：

| 项目 | 建议 |
|------|------|
| 画幅 | **9:16 竖屏** |
| 单镜时长 | **10–15 秒**（H3 支持 4–15 秒整数） |
| 单集结构 | 4–8 个镜头拼接 ≈ 60–120 秒 |
| 模式 | **全能参考**：角色锁脸图 + 场景图 |
| 分辨率 | 先 768P 测戏，定稿再 2K |

## H3 核心公式（务必遵守）

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

- 台词必须**逐字写出**，不能写「她说了句感人的话」
- 每个上传文件都要写清用途：`@图片1 是人物参考（锁脸）`
- 想一镜到底：明确写「不要切镜」；默认 H3 会切镜
- 不要配乐：文末写 `non_diegetic_music: N/A`
